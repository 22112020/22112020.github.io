# TGQ — UI/UX Design

## Webapp

`UI/webapp/` — Dashboard web yang connect ke FastAPI backend.

```
webapp/
├── index.html      Halaman utama
├── css/style.css   Dark theme — gold accent (#f0c040)
└── js/app.js       Fetch API → /status, /analyze
```

**Run:** buka `index.html` langsung di browser (static) atau serve via API backend.

## Android Prototype

`UI/android/` — Mockup tampilan Android app.

```
android/
└── index.html      Phone frame HTML prototype
```

Bisa dibuka di browser untuk preview tampilan mobile. Theme gelap dengan aksen emas.
